# biom5350-seq-tools
This repository is including a Python script for analyzing DNA sequences from FASTA files.
## Usage
```
python gc_content.py example.fasta
```
## Output
It will calculate and display the GC & AT contents, sequence length for each DNA sequence, and the mean GC contents through all sequences
